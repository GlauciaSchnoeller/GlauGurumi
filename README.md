# GlauGurumi 🧶

Bem-vindo(a) ao meu cantinho do crochê!  
Este repositório contém a criação de uma página estática para divulgar os trabalhos da GlauGurumi.  
GlauGurumi é uma página pessoal para **divulgar meus trabalhos de amigurumi**, compartilhar fotos das peças que crio e oferecer um canal de contato.  

⚠️ **Site em construção** – novas fotos e conteúdos estão a caminho!  

---

## 🌟 Funcionalidades

- 🖼️ **Galeria de fotos** dos meus trabalhos recentes  
- 🌐 **Links de contato e redes sociais**  
- 📬 **Formulário para enviar mensagens**  

---

## 🧑‍🎨 Sobre mim

Sou uma exploradora de crochê e outros tipos de artesanato.  
Meu objetivo é compartilhar minhas criações e reproduções de peças.
